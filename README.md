# Ritesh Tiwari — Portfolio

Professional portfolio for Ritesh Tiwari, Full-Stack Developer.

## Stack
- React + Vite
- React Router
- Lucide React
- Responsive CSS

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The portfolio includes a responsive landing page, dark/light mode, selected projects and individual project case-study routes.
